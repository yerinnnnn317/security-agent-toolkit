10월 8일 학습 정리: 보안 관제 자동화 파이프라인 구축



1\. 오늘 한 일

어제까지 개별로 실행하던 보안 경보 요약과 보고서 생성 코드를 하나로 묶었습니다.

설정 파일 분리, 알림 연동, 예외 처리, 단위 테스트까지 완성하여 명령 한 번으로 작동하는 파이프라인을 만들었습니다.





2\. 주요 구현 파일 및 학습 내용



**\[config.json]** 설정 분리

코드 안에 모델명이나 주소를 직접 적는 하드코딩을 없앴습니다.

API 키는 .env 파일에 보관하고, 모델 이름과 알림 주소 같은 일반 설정은 config.json 파일로 따로 뺐습니다.

파일을 읽을 때 필수 키가 빠졌는지 자동으로 검사하도록 했습니다.



**\[notifier.py]** 알림 연동 및 예외 처리

보고서 작성이 완료되면 웹훅을 통해 알림 서버로 메시지를 보냅니다.

알림 서버가 꺼져 있거나 오류가 나도 작업이 멈추지 않도록 try-except 예외 처리를 적용했습니다.



**\[pipeline.py]** 파이프라인 통합

설정 읽기, 경보 요약, 위험도 정렬, 총평 작성, 보고서 저장, 알림 전송까지 전 과정을 하나로 묶었습니다.

터미널에서 python pipeline.py 명령 한 번만 입력하면 전체 과정이 자동으로 진행됩니다.



**\[test\_agent\_core.py]** 코드 리뷰 및 단위 테스트

assert 구문을 사용해서 주요 함수들이 정답 값을 잘 리턴하는지 9가지 항목을 검사하는 테스트 코드를 만들었습니다.

대소문자나 공백 문제로 생기는 논리 에러를 strip()과 lower() 함수로 해결했습니다.
